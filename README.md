# 点点 · 四页独立交互原型

基于 Figma 设计稿还原，设计基准为 393 × 852，适配手机与电脑浏览器。使用 HTML、CSS 和原生 JavaScript 实现，无构建依赖。

## 一、页面功能

### 1. 小红书首页

- 笔记布局保持小红书原有状态。
- 仅支持进入点点 AI 首页和搜索页（左上和右上button）。
- 所有页面统一使用首页的手机状态栏，时间实时显示北京时间。
- 首页部分无图片，默认灰色封面。

### 2. 点点 AI 首页

- 页面内容由上至下渐变出现。
- 点击“种草推荐 / 出行攻略 / 好物测评”卡片，将示例问题自动填入当前页面的输入框，并进入编辑状态；用户可以修改问题后发送；输入框随编辑状态切换样式。
- 点击“为你推荐”中的快捷问题，一键发送。
- 发送时显示消息气泡动画，随后播放笔记翻阅特效和加载进度条。
- 笔记翻阅固定为 1.8 倍速，约 4.83 秒后结束，进入空态视图。
- 刷新后重新回到初始状态。

### 3. 搜索页

- 搜索结果采用双列瀑布流，支持持续向下滚动，笔记素材可重复展示。
- 累计达到 8 条有效曝光后，在右列即将进入视口的位置插入一次“试试问点点”组件。
- 单条笔记至少 50% 面积进入视口，并连续停留 300ms，才计为一次有效曝光。
- 同一列表项重复进入视口不重复计数；重复素材作为新的列表项展示时，可以重新计数。
- 打开对话窗口或切换至后台时暂停曝光统计；关闭窗口后保留计数和滚动位置。
- 重新搜索或切换支持的分类时，重置曝光统计。

### 4. 搜索页对话窗口

- 点击“试试问点点”后弹出对话窗口，自动填入对应问题。
- 用户可以再次修改文字后发送。
- 点击输入框后，输入区域切换至编辑样式。
- 支持多行输入、发送状态变化，以及关闭后重新打开时保留本次浏览的草稿。
- 搜索页对话窗口与 AI 首页输入区域分别维护。

### 键盘与输入体验

- 手机端使用【真实输入框】，点击后调用设备的系统键盘，同时隐藏键盘切图。
- 电脑端保留【苹果键盘切图】作为视觉展示，实际使用电脑键盘和输入法输入。
- 输入框随内容自动增高，空白内容不可发送。
- Enter 发送，Shift + Enter 换行；中文输入法选词过程中按 Enter 不会误发送。
- 直接打开对话链接时不强制唤起键盘，点击输入框即可。
- 草稿、点赞和演示消息仅保存在当前浏览内存中，刷新后清空。

！！目前未接入真实 AI 服务。未提供设计稿的市集、发布、消息、用户、商品等入口仅显示提示。

## 二、项目架构

四个页面分别维护自己的 HTML、CSS 和 JavaScript。共享内容集中管理，方便后续单独增加页面功能。

| 页面 | 文件目录 | 页面路由 |
| --- | --- | --- |
| 小红书首页 | `dist/pages/home/` | `#/home` |
| 点点 AI 首页 | `dist/pages/ai/` | `#/ai` |
| 搜索页 | `dist/pages/search/` | `#/search` |
| 搜索页对话窗口 | `dist/pages/chat/` | `#/chat?from=search&q=梨形夏季穿搭` |

### 页面组织

- 每页的结构、样式和交互分别放在对应目录的 HTML、CSS、JS 文件中。
- 页面通过 `dist/app.js` 提供的导航接口切换，不直接读取或修改其他页面的 DOM。
- 页面模板提前加载，切换时保留已有视图与滚动位置。
- 输入框在用户点击时同步聚焦，以满足手机浏览器唤起系统键盘的要求。

### 共享文件

| 文件 | 用途 |
| --- | --- |
| `dist/app.js` | 页面加载、路由和弹窗导航 |
| `dist/shared/base.css` | 全局基础样式 |
| `dist/shared/ui.js` | 状态栏、北京时间等共享界面功能 |
| `dist/shared/note-card.js` | 笔记卡片渲染 |
| `dist/shared/viewport.js` | 可视区域适配与键盘状态处理 |
| `dist/assets/` | 本地图片、SVG 和键盘切图 |
| `dist/assets/manifest.json` | 已使用素材记录 |

## 三、后续修改方式

### 修改页面内容与样式

进入对应页面目录：

- 修改 `.html`：调整页面结构。
- 修改 `.css`：调整尺寸、间距、颜色和动画。
- 修改 `.js`：调整交互逻辑与页面状态。

仅增加现有页面内容时，通常无需修改导航文件 `dist/app.js`。

### 修改笔记内容

- 首页：编辑 `dist/pages/home/data.js`。
- 搜索页：编辑 `dist/pages/search/data.js`。

两个页面的数据独立维护，互不影响。

### 修改 AI 首页

- 推荐问题和功能卡片：编辑 `dist/pages/ai/ai.js` 中的 `questions` 与 `features`。
- 输入框、发送与加载状态：编辑 `dist/pages/ai/ai.js`。
- 页面及输入区域样式：编辑 `dist/pages/ai/ai.css`。
- 笔记翻阅动画：编辑 `dist/pages/ai/deck.js`。

详细说明见 `dist/pages/ai/README.md`。

### 修改搜索页曝光规则

编辑 `dist/pages/search/exposure.js`，调整可见面积比例、停留时间及相关曝光逻辑。

### 修改搜索页对话窗口

编辑 `dist/pages/chat/chat.js` 和 `chat.css`。

后续接入真实 AI 时，可替换 `chat.js` 中 `submit()` 的演示回复逻辑；AI 首页的发送逻辑需在其独立模块中分别接入。

### 替换高清图片

覆盖 `dist/assets/` 中同名、同格式的文件即可。

- 可以使用原图 2 倍或 3 倍分辨率，无需保持相同像素尺寸。
- 保持宽高比、透明背景和留白一致，避免拉伸或位置偏移。
- 页面显示尺寸由 CSS 控制，更换高清图片不会自动改变布局。
- SVG 为矢量素材，可无损缩放。

## 四、预览与发布

### 在线访问

GitHub Pages 部署成功后，用户可通过公开链接访问，无需登录 GitHub，也可直接使用 iPhone Safari 打开。

### 本地预览

安装 Node.js 24，在项目目录运行：

`npm start`

然后打开：

`http://localhost:4173/`

同一 Wi-Fi 下，手机可访问：

`http://电脑局域网IP:4173/`

电脑需要允许本地网络访问。请通过 HTTP 服务预览，直接双击 HTML 文件无法正常加载页面模块与模板。

### 自动发布

发布流程位于 `.github/workflows/pages.yml`。

将更新推送至 `main` 分支后，GitHub 会先运行检查和测试，再将 `dist/` 发布到 GitHub Pages。后续更新继续使用同一个网站链接。

本地 `.openai/` 配置不会上传。

## 五、验证情况

已完成桌面浏览器的视觉与主要流程检查，并提供以下验证命令：

- `npm test`：验证曝光统计边界、暂停与重置，以及笔记翻阅动画的速度和结束逻辑。
- `npm run check`：检查 JavaScript 语法、本地素材是否存在，以及是否残留临时 Figma 素材链接。

手机键盘已按浏览器原生输入机制实现，但尚未完成实体 iPhone 的键盘弹出与布局适配测试。
