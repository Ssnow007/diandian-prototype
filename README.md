# 点点 · 四页独立交互原型

基于 Figma 文件 `bGMwuQZCmAulWeFM0TCeNq`，设计基准 393 × 852。纯 HTML、CSS、原生 JavaScript，无构建依赖。

## 打开

GitHub Pages 发布后，任何人都可通过公开链接访问，也可直接在 iPhone Safari 打开。
本地预览：安装 Node.js 24 后，在本目录运行 `npm start`，打开 `http://localhost:4173/`。
同一 Wi-Fi 下，手机也可打开 `http://电脑局域网IP:4173/`（电脑需允许本地网络访问）。
请通过 HTTP 服务打开；直接双击 HTML 的 `file://` 方式不能加载 ES 模块和页面模板。

## 页面解耦

每页的 HTML、CSS、JS 独立维护；页面通过 `app.js` 注入的 `navigate/openChat` 通信，不相互读取或修改 DOM。
页面模板预先加载，跳转只切换视图。这样既保留滚动位置，也确保 iPhone 点击推荐项时可在同一次用户操作里同步聚焦输入框。

| 页面         | 编辑目录             | 路由                                 |
| ------------ | -------------------- | ------------------------------------ |
| 小红书首页   | `dist/pages/home/`   | `/#/home`                            |
| 点点 AI 首页 | `dist/pages/ai/`     | `/#/ai`                              |
| 搜索页       | `dist/pages/search/` | `/#/search`                          |
| 对话窗口     | `dist/pages/chat/`   | `/#/chat?from=search&q=梨形夏季穿搭` |

- 增加页面内容：编辑对应 `页面名.html`、`页面名.css`、`页面名.js`。
- 增加笔记：编辑该页的 `data.js`。首页与搜索页的数据互不依赖。
- 增加 AI 首页推荐问题／卡片：编辑 `pages/ai/ai.js` 的 `questions/features`。
- 调整曝光阈值：编辑 `pages/search/exposure.js` 的默认 `threshold/dwell`。
- 调整对话交互／后续接入 AI：编辑 `pages/chat/chat.js`，替换 `submit()` 内演示回复。
- 共享基础：`shared/base.css`、`shared/ui.js`（状态栏、北京时间）、`shared/note-card.js`（笔记卡片）、`shared/viewport.js`（可视区域与键盘）。
- 导航关系集中在 `app.js`。新增内容无需改变它。
- `assets/` 全部为本地 Figma 素材；SVG 保留原始文件尺寸。`assets/manifest.json` 记录已使用资产。

## 键盘与输入

- iPhone/iPad/Android：真实 `textarea`，通过用户点击同步聚焦，唤起设备配置的系统键盘；苹果键盘切图隐藏。设备可能使用第三方输入法或外接键盘，网页尊重设备设置。
- 电脑：保留原稿苹果键盘切图，使用电脑键盘／中文输入法正常输入；切图是视觉示意，没有独立输入法功能。
- 直接打开对话路由时不会强制弹键盘，点击输入框即可。
- 16px 输入字号避免 iPhone 聚焦放大；VisualViewport 跟随键盘可视区域。
- 原生输入法组合过程中 Enter 不发送；Enter 发送，Shift+Enter 换行。
- 空白文本禁用发送；多行输入自动长高；关闭／重开保留本次浏览的草稿。
- 草稿、点赞与演示消息仅保存在内存中，刷新即清空；未接入真实 AI 服务。

## 曝光与瀑布流

搜索页按实际滚动容器计算面积：单卡片至少 50% 可见且连续停留 300ms 才计数。离开中断计时；重复进入同一列表项只计一次。
累计 8 个有效列表项后，在即将进入视口的右列位置插入一次“试试问点点”。图片重复但列表项 ID 不同，可作为新的曝光。
打开弹窗或切到后台暂停统计；关闭弹窗保留计数与滚动位置；重新搜索或切换支持的分类重置。
无限滚动复用原稿笔记素材。首页灰色封面忠实保留原稿，不是图片加载失败。

## 范围与验证

四页主流程可用；其余市集／发布／消息／用户／商品等没有对应设计稿的入口提供提示，不虚构页面。
已完成桌面浏览器视觉与流程检查，以及曝光边界自动测试。iPhone 键盘已按浏览器原生机制实现，但本次环境没有实体 iPhone，未做真机键盘弹出测试。

`npm test`：曝光 50%/300ms、第 8 条、去重、弹窗与后台暂停、重置。
`npm run check`：JavaScript 语法、本地素材存在性、临时 Figma URL 检查。

GitHub Pages 通过 `.github/workflows/pages.yml` 自动发布 `dist/`。推送到 `main` 后，先运行检查与测试，再更新网站。旧的本地 `.openai/` 配置不会上传。

## 替换高清图片

覆盖 `dist/assets/` 中同名同格式文件，保持宽高比、透明背景和留白一致；可使用 2× 或 3× 分辨率，页面显示尺寸由 CSS 控制。SVG 可无损缩放。
